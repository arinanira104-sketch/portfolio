// UX концепт · мини-игра

Додо Блоки

Block Puzzle · UX-концепция для программы лояльности Додо Пицца · 2026

UX Концепт Мини-игра Dodo Pizza Block Puzzle UX-концепция и визуальный дизайн

UX решения

Игра встроена в приложение Додо как отдельный раздел — снижает порог входа. Онбординг — модальное окно поверх поля. Карточка заказа добавляет нарратив. Рейтинг с таймером мотивирует возвращаться. Петля «игра → покупка → игра».

Брендирование

Два слоя по гайду Shift: UI строго по бренду (#FF6600, Dodo Rounded); игровое поле — казуальный clay-арт. Термины говорят языком бренда. Фиолетовый исключён — он за Додо Комбо.

Визуальная стилистика

Принцип двух слоёв: строгий бренд в UI, свободный clay-арт в игровой зоне. Без фиолетового, тёмного фона и перегруза брендингом.
