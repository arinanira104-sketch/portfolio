Full-cycle work on a series of casual mobile games at Sonakai studio — from wireframes and UX flows to final UI, illustrations, and animations. Designed and shipped three published titles available on Amazon Appstore today: two match-3 puzzlers and a nail salon simulator.

Each game required a complete visual language — UI kit, screens, popups, icons, promo materials — and consistent execution across them. Worked alongside game designers and developers, contributing to usability testing and iterating UX patterns based on player feedback.

// TITLE · 01

Fairy Kingdom Princess

Match-3 Fairytale · Full UI/UX & Art Production

View on Amazon

A casual match-3 game set in a magical fairy kingdom. Designed the complete visual language — from the UI kit and component system to game screens, popups, monetisation flows, and promotional materials. Every popup follows a consistent structure (header ribbon, corner close, bottom CTA) so players navigate without friction across the game.

— UI Kit & Foundation —

Buttons, progress bars, ribbons, currency icons, avatar frame, coin stacks — a reusable component system.

— Core Game Screens —

Main menu, level map across three visual themes, gameplay HUD, and shop with three tab states.

— Popups & Monetisation —

Lucky Spin, Golden Ticket / Battle Pass, Settings, Out of Moves, Exit confirmation. Designed for clarity and conversion.

— Icons, Props & Extras —

Daily Tasks, Free Gift, rewarded ad placements, 15+ candy/gem icons in multiple states, and chest animations.

— Deliverables —

  • UI kit: buttons, ribbons, currency icons, frames, coin stacks
  • Main menu, gameplay HUD, level map (3 themes)
  • Shop with three tab states
  • Lucky Spin, Golden Ticket / Battle Pass popups
  • Daily Tasks, Free Gift, Settings, Out of Moves
  • 15+ game piece icons with multiple states
  • Chest open / closed animation states
  • 3 unique level map environments
  • Rewarded ad placements integrated into environment
  • Store banners and promotional materials

— Design Decision —

"The visual language balances readability during fast-paced gameplay with a whimsical fairy-tale aesthetic. All popups follow one component structure — same ribbon, same close, same CTA — so players never have to relearn the interface."

// TITLE · 02

Funny Candy Land

Match-3 Confectionery · UI & 2D Art

View on Amazon

Designed the visual style and game assets for a casual mobile match-3 in a confectionery aesthetic. The challenge was building a coherent visual world from candy elements while keeping the game pieces instantly readable during fast play.

— Promo Cover —

Store promotional visuals: gameplay preview in a device mockup and vertical promo composition.

— Game Piece Icon Set —

15 unique candy elements: orange slice, jelly, donut, cookie, chocolate, lollipop and more. Chocolate chest in closed and open states.

— Deliverables —

  • Store promotional visual with device mockup
  • Vertical promo composition for Amazon listing
  • Gameplay HUD: moves counter, collection progress, lives system
  • Match-3 grid with candy-themed game pieces
  • 15 unique candy element icons
  • Chocolate chest: closed & open animation states
