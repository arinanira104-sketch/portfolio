// Challenge

The app had no design system —
just inconsistent legacy screens

Navigation was cluttered, screens had no shared visual language, and the overall aesthetic felt dated next to competing romance games. The team needed a full redesign — not a patch job.

// Process

  1. UX audit of 20+ existing screens — mapping navigation problems, hierarchy failures and visual inconsistencies
  2. Competitive benchmarking — 5+ top romance mobile games studied for UX patterns and visual direction
  3. Wireframes first — all flows and layouts drafted before any visual design work began
  4. Design system built from scratch — colour palette, typography, component library, spacing rules
  5. 7+ new feature screens designed, sliced and handed off to developers with full documentation

// Навигация

Нет универсальной кнопки «Назад». Нижний навбар перегружен, ивенты и магазин дублируют друг друга. Пользователи теряются — особенно новички.

// Профиль

Достижения и кат-сцены в одной ленте без фильтрации. Жетоны не кликабельны, описаний нет. Визуально — устарелые градиенты и блёстки без иерархии.

// Онбординг

Никто не объясняет, что такое аметисты и эликсиры, где и зачем их тратить. Нет обучения — новичок брошен.

// Визуал

«Слишком много розового», разные стили иконок, несогласованные эффекты. Интерфейс не выглядит современным рядом с конкурентами.

// Итог

Seven Hearts — первый фриланс-проект такого масштаба. Единственный дизайнер, но принимали работу продюсер, ПМ, геймдизайнеры, программисты, арт-лиды и художники — почти весь состав, и каждый смотрел на своё. Научилась держать единый стиль на 20+ экранах и при этом проводить каждое решение через всю команду. Главное открытие: Seven Hearts живёт на стыке игры и приложения — визуальный язык должен был работать в обоих мирах. Это и стало самой интересной задачей проекта.
