Funny Candy Land

Match-3 Puzzler · Casual · Sweet

A vibrant match-3 puzzle game set in a world of sweets and candy. Colourful UI, game icons, HUD elements and promotional store assets — delivered for a complete production pipeline targeting Amazon Appstore.

Platform Amazon Appstore
Role 2D Artist · UI Designer
// Design Note

"A fully saturated candy world — the challenge was keeping the palette vibrant without losing readability. Match-3 games live or die by how fast players read the board, so every icon and HUD element needed clear visual hierarchy beneath all that sweetness."

// Итог

Six games in a row — not just a large volume of work. Each time: a new visual language, a new audience, a new style. Fairy Kingdom and Candy Land — fantasy match-3 with illustrations; Beauty Simulators — different aesthetics, different interaction patterns, characters built around different themes. Learned to step into a new visual world quickly and keep it coherent from the first screen to the store icon. All 6 games published on Amazon, iOS and Android.
